# Data access and raw-input placement

The raw LCL, CER/ISSDA and survey data are not redistributed in this repository. A reproducer must obtain the source data lawfully from the official archives below and place the required files under `data/raw/` using the exact filenames and structure in `expected_input_structure.txt`.

## Official source and access routes

### Low Carbon London (LCL)

This workflow uses the UK Data Service release:

**Low Carbon London Project: Data from the Dynamic Time-of-Use Electricity Pricing Trial, 2013**  
UK Data Service study number: **7857**  
DOI: https://doi.org/10.5255/UKDA-SN-7857-2

The UK Data Service catalogue states that the collection is available to registered users subject to the End User Licence Agreement. The collection contains the smart-meter consumption data and consumer survey data used by this workflow.

For this reproduction, the required LCL data tables are:

- `consumption_n.csv`
- `survey_questions.csv`
- `survey_answers.csv`

The workflow uses the UK Data Service Group N wide-format consumption table. Do not substitute a different Low Carbon London distribution whose file layout or household grouping differs from the UK Data Service study used here.

### CER / ISSDA

This workflow uses:

**CER Smart Metering Project - Electricity Customer Behaviour Trial, 2009-2010**  
Irish Social Science Data Archive (ISSDA)  
DOI: https://doi.org/10.7929/ISSDA/BX59EU

The ISSDA catalogue states that the data are available to request for non-commercial research and teaching purposes. Follow the current access instructions on the DOI landing page. The smart-meter read files may need to be downloaded separately because of archive download-size limits.

For this reproduction, the required CER/ISSDA material is:

- `File1.txt`
- `File2.txt`
- `File3.txt`
- `File4.txt`
- `File5.txt`
- `File6.txt`
- `Smart meters Residential pre-trial survey data.csv`
- `SurveySourceData_survey_original/RESIDENTIAL PRE TRIAL SURVEY.pdf`
- `SurveySourceData_survey_original/SME and Residential allocations.xlsx`
- `SurveySourceData_survey_original/File Manifest - Smart Meter Electricity Trial Data v1.0.1.pdf`

Use the provider filenames exactly as listed. Do not preprocess, concatenate or rename the raw files before placing them in the repository structure.

## Prepare the directories

From the repository root:

```bash
bash workflows/prepare_raw_inputs.sh
```

This creates the required directories and lists any missing files. It does not search the user's computer because provider downloads can be stored anywhere and duplicate filenames can exist.

If an existing raw-data directory already contains the documented `LCL/` and `ISSDA_CER/` trees, the required files can be copied explicitly:

```bash
bash workflows/prepare_raw_inputs.sh --source-root /path/to/raw
```

Then verify:

```bash
bash workflows/check_raw_inputs.sh
```

Expected result:

```text
RAW INPUT CHECK: PASS (13 required files)
```

Additional LCL provider documentation may be retained locally for reference, but `check_raw_inputs.sh` requires only the three LCL data tables listed above.

Do not prepopulate `data/processed/` or `outputs/` with author-generated intermediate files. Those files are regenerated by the workflow.
